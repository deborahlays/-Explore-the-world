Como as 3 Bibliotecas Foram Utilizadas

Visão técnica sobre a importação via CDN e o código JavaScript responsável por dar vida a cada componente.

Biblioteca 1 v11 CDN

Swiper.js

Biblioteca moderna para criação de carrosséis e sliders touch responsivos com suporte a aceleração por hardware e múltiplos efeitos 3D.

// Inicialização em JS:
const swiper = new Swiper('.destinos', {
  effect: 'coverflow',
  centeredSlides: true,
  autoplay: { delay: 3800 },
  pagination: { el: '.pagination' }
});
Onde foi usada: Carrossel de destinos Ver componente →
Biblioteca 2 v1.9 CDN

Leaflet.js

Principal biblioteca open-source para mapas interativos web. É leve (apenas 42KB de JS), compatível com dispositivos móveis e não necessita de chaves de API pagas.

// Criação do mapa e marcador:
const map = L.map('mapa').setView([20, 0], 2);
L.tileLayer('https://...').addTo(map);
L.marker([lat, lng])
  .addTo(map)
  .bindPopup('<h4>Destino</h4>');
Onde foi usada: Mapa mundial e popups Ver componente →
Biblioteca 3 v2.3 CDN

AOS (Animate On Scroll)

Permite aplicar animações CSS pré-construídas a qualquer elemento HTML disparadas no momento exato em que o usuário rola a tela até a posição do componente.

// No HTML e JS:
<div data-aos="fade-up" data-aos-delay="100">

AOS.init({
  duration: 850,
  once: true
});
Onde foi usada: Todos os cards e títulos Ver componente →
