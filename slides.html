Fundamentos

O que são Bibliotecas JavaScript?

Por que utilizar bibliotecas prontas em vez de desenvolver tudo do zero?

Produtividade & Tempo

Elimina a necessidade de "reinventar a roda". Soluções complexas como gestos touch e cálculos matemáticos já vêm prontas e testadas.

Compatibilidade Total

As bibliotecas tratam variações entre navegadores (Chrome, Safari, Firefox, Edge) e adaptações para celulares e tablets.

Inclusão Simples via CDN

Basta incluir as tags <link> para o CSS e <script> para o JS fornecidas por redes de distribuição como cdnjs e jsDelivr.

Regra do Projeto: Usar 3 bibliotecas de finalidades distintas complementando HTML, CSS e JavaScript.
Biblioteca 1 de 3 Carrossel & Sliders

Swiper.js v11

O carrossel mobile-first mais moderno da Web atual.

🎯 Para que serve: Cria sliders de imagens, produtos e depoimentos com suporte completo a gestos touch, arraste pelo mouse e aceleração de hardware CSS3.
✨ Recursos que utilizamos:
  • Efeito 3D coverflow com rotação e profundidade
  • Navegação por setas e paginação por bullets clicáveis
  • Autoplay automático pausável com passar do mouse
// 1. Importação no HTML: <link rel="stylesheet" href=".../swiper-bundle.min.css">
<script src=".../swiper-bundle.min.js"></script>

// 2. Inicialização em JS: const swiper = new Swiper('.destinos', {
  effect: 'coverflow',
  grabCursor: true,
  centeredSlides: true,
  autoplay: { delay: 3800 },
  pagination: { el: '.swiper-pagination' }
});

Biblioteca 2 de 3 Mapas Geográficos & Satélite

Leaflet.js v1.9

Mapeamento global com fotos reais de satélite e marcadores interativos.

🎯 Para que serve: Renderiza mapas interativos, rotas, camadas e marcadores georreferenciados (Latitude e Longitude) sem custos ou chaves de API restritivas.
✨ Recursos que utilizamos:
  • Satélite Híbrido: Imagens orbitais de alta definição (Esri World Imagery) + rótulos de cidades
  • Controle de camadas para alternar entre Satélite e Mapa Urbano
  • Marcadores animados com L.divIcon e popups com fotos e preços
  • Navegação suave automática com a função map.flyTo()
// 1. Imagem de Satélite Esri World Imagery: const satelite = L.tileLayer(
  'https://server.arcgisonline.com/.../tile/{z}/{y}/{x}'
).addTo(mapa);

// 2. Controle de alternância de camadas: L.control.layers({
  '🛰️ Satélite': satelite,
  '🗺️ Urbano': ruas
}).addTo(mapa);

Biblioteca 3 de 3 Animações de Scroll

AOS (Animate On Scroll)

Efeitos visuais dinâmicos conforme o usuário rola a página.

🎯 Para que serve: Detecta a posição do scroll da página e aciona automaticamente animações CSS quando um elemento entra no campo visual do usuário.
✨ Vantagens técnicas:
  • Não precisa escrever centenas de linhas de CSS de keyframes
  • Configuração declarativa diretamente no HTML via data-aos
  • Suporte a delays em cascata: data-aos-delay="200"
// 1. Atributo no elemento HTML: <div data-aos="fade-up" data-aos-delay="250">
  <h3>Card de Pacote</h3>
</div>

// 2. Inicialização global em JavaScript: AOS.init({
  duration: 850,
  once: true,
  easing: 'ease-out-cubic'
});

Biblioteca Bônus Microinterações

canvas-confetti

Feedback comemorativo com física e partículas no Canvas HTML5.

🎯 Por que adicionamos: Mencionada pelo professor como exemplo na aula! Proporciona feedback visual instantâneo e prazeroso no momento em que o usuário confirma a reserva de uma viagem.
✨ Como funciona: Cria dinamicamente um elemento <canvas> sobreposto à tela e simula a gravidade, rotação e velocidade de dezenas de confetes coloridos.
// Disparo comemorativo via JS: confetti({
  particleCount: 80,
  spread: 65,
  origin: { x: 0.5, y: 0.7 }
});

Conclusão & Aprendizados

O que a realização deste trabalho agregou à nossa formação.

Compreensão da Arquitetura Web Moderna: Aprendemos a integrar CSS e JS externos via CDN de maneira organizada, sem conflitos entre bibliotecas.

Qualidade de Experiência do Usuário (UX): O uso de animações conscientes (AOS) e microinterações (confetes) torna o site profissional e atrativo.
